โมเลกุลในสารละลายชนกันนับล้านครั้งต่อวินาที — แล้วทำไมมีแค่บางครั้งเท่านั้นที่ "นับ" เป็นปฏิกิริยา

ทุกปฏิกิริยาเริ่มจากการชน
แต่ไม่ใช่ทุกการชนจะกลายเป็นปฏิกิริยา

ทฤษฎีการชน (collision theory) อธิบายว่าอนุภาคของสารตั้งต้นต้องชนกันก่อนจึงจะเกิดปฏิกิริยาได้ แต่การชนที่จะ "นับ" ต้องผ่านเงื่อนไขสองข้อพร้อมกัน — เนื้อหาทั้งหมดของบทนี้คือการอธิบายสองเงื่อนไขนั้น และผลของอุณหภูมิที่มีต่อเงื่อนไขข้อแรก

2.1

เงื่อนไขของการชนที่ทำให้เกิดปฏิกิริยา

จากภาพเปิดหัวข้อ การชนที่จะเกิดปฏิกิริยาได้ต้องมีครบสองเงื่อนไข

  1. พลังงานมากพอ
    อนุภาคต้องชนกันด้วยพลังงานจลน์รวมกันไม่น้อยกว่าค่าต่ำสุดค่าหนึ่ง เรียกว่า พลังงานก่อกัมมันต์ (Eₐ) — ถ้าชนกันเบาไป พันธะเดิมจะไม่แตกออก
  2. ทิศทางถูกต้อง
    อนุภาคต้องหันด้านที่จะเกิดพันธะใหม่เข้าหากัน ถ้าชนกันแบบเฉียงหรือหันด้านผิด แม้พลังงานจะมากพอ ก็ไม่เกิดปฏิกิริยา

ต้องครบทั้งสองข้อ ขาดข้อใดข้อหนึ่งไป การชนนั้นจะไม่ "นับ" เป็นปฏิกิริยา

"พลังงานมากพอ" เปรียบได้กับการผลักลูกบอลขึ้นเนิน — ต้องออกแรงมากพอจะให้ลูกบอลข้ามยอดเนินไปได้ ถ้าแรงไม่พอ ลูกบอลก็จะไหลกลับลงมาที่เดิม ไม่ว่าจะพยายามกี่ครั้งก็ตาม

ลองพิจารณาปฏิกิริยา NO(g) + NO₃(g) → 2NO₂(g) ซึ่งเป็นตัวอย่างที่ใช้อธิบายเรื่องทิศทางการชนในหนังสือเรียน ปฏิกิริยานี้คือการถ่ายโอนอะตอมออกซิเจน — อะตอม N ของ NO ต้องหันเข้าชนกับอะตอม O ที่ปลายของ NO₃ เพื่อรับออกซิเจนมา พันธะใหม่ N–O จึงจะเกิดขึ้นได้ตรงตำแหน่ง ถ้าหันด้าน N ของ NO₃ เข้าชนแทน (ซึ่งถูกอะตอม O ทั้งสามบังอยู่ ชนไม่ถึงอยู่แล้ว) ต่อให้ชนแรงแค่ไหนก็ไม่เกิดปฏิกิริยา

2.2

พลังงานก่อกัมมันต์ (Eₐ)

เมื่ออนุภาคชนกันด้วยพลังงานมากพอและถูกทิศทาง จะไม่กลายเป็นผลิตภัณฑ์ในทันที แต่ผ่านสถานะกึ่งกลางที่ไม่เสถียรก่อน เรียกว่า สารเชิงซ้อนกัมมันต์ (activated complex) หรือ สถานะทรานซิชัน (transition state) — พันธะเดิมกำลังแตก พันธะใหม่กำลังเกิด พร้อมกันในช่วงเสี้ยววินาทีนั้น

Eₐ (ก่อกัมมันต์)ความสูงของเนินจากระดับสารตั้งต้นถึงจุดสูงสุด — ยิ่งเนินสูง ยิ่งต้องใช้อนุภาคที่พลังงานสูงมากในการข้ามไปได้ ปฏิกิริยายิ่งช้า
สารเชิงซ้อนกัมมันต์อยู่ที่ยอดเนินพอดี พลังงานสูงที่สุด ไม่เสถียรที่สุด อยู่ได้ชั่วขณะแล้วสลายไปเป็นผลิตภัณฑ์ (หรือย้อนกลับเป็นสารตั้งต้น)
ΔE ของปฏิกิริยาผลต่างระดับพลังงานระหว่างสารตั้งต้นกับผลิตภัณฑ์ เป็นคนละค่ากับ Eₐ และไม่เกี่ยวข้องกับอัตราการเกิดปฏิกิริยาเลย — ต่อให้ปฏิกิริยาคายพลังงานออกมามาก (ΔE ติดลบมาก) ก็ยังเกิดช้าได้ ถ้า Eₐ ยังสูงอยู่
2.3

Eₐ ไปข้างหน้า และ Eₐ ย้อนกลับ

เนินเดียวกันในหัวข้อ 2.2 วัดความสูงได้ 2 ทาง ถ้ายืนฝั่งสารตั้งต้นมองขึ้นไปยอดเขา ความสูงที่ต้องปีนคือ Eₐ ไปข้างหน้า — ทิศทางที่ปฏิกิริยาดำเนินไปจริง แต่ถ้ายืนฝั่งผลิตภัณฑ์มองขึ้นไปยอดเขาลูกเดียวกัน ความสูงที่ต้องปีนคือ Eₐ ย้อนกลับ (Eₐ') — ทิศทางที่ผลิตภัณฑ์จะเปลี่ยนกลับเป็นสารตั้งต้น ยอดเขาอยู่ที่เดิมเสมอ ต่างกันแค่จุดเริ่มยืน

ผลิตภัณฑ์อยู่ต่ำกว่าสารตั้งต้น (ปฏิกิริยานี้คายพลังงาน) ฝั่งผลิตภัณฑ์จึงต้อง "ปีน" สูงกว่า นั่นคือ Eₐ' มากกว่า Eₐ เสมอ — ผลต่างของความสูงที่ปีนสองฝั่งนี้เอง คือที่มาของสมการ:

Eₐ' = Eₐ − ΔE
ปฏิกิริยาดูดพลังงาน (endothermic, ΔE > 0)ผลิตภัณฑ์อยู่สูงกว่าสารตั้งต้น ทำให้ Eₐ' < Eₐ — ย้อนกลับง่ายกว่าไปข้างหน้า
ปฏิกิริยาคายพลังงาน (exothermic, ΔE < 0)ผลิตภัณฑ์อยู่ต่ำกว่าสารตั้งต้น ทำให้ Eₐ' > Eₐ เสมอ — ย้อนกลับยากกว่าไปข้างหน้า
ตัวอย่างตัวเลข

ปฏิกิริยาหนึ่งมี Eₐ (ไปข้างหน้า) = 75 kJ/mol และ ΔE = −40 kJ/mol (คายพลังงาน) จะได้

Eₐ' = 75 − (−40) = 115 kJ/mol

Eₐ' (115) มากกว่า Eₐ (75) — ตรงตามที่คาดว่าปฏิกิริยาคายพลังงานจะย้อนกลับยากกว่าไปข้างหน้า

2.4

ปฏิกิริยาหลายขั้นตอน — ขั้นกำหนดอัตราและสารมัธยันตร์

ปฏิกิริยาส่วนใหญ่ไม่ได้เกิดในขั้นตอนเดียว แต่ผ่านหลายขั้นย่อย แต่ละขั้นมีเนินพลังงานของตัวเอง กราฟจึงมีหลายยอด — ยอดที่สูงที่สุดคือขั้นกำหนดอัตรา (rate-determining step) เพราะเป็นขั้นที่ช้าที่สุด (Eₐ สูงสุด) ส่วนสารมัธยันตร์ (intermediate)คือสารที่เกิดขึ้นระหว่างทางแล้วถูกใช้ไปในขั้นถัดไป ไม่ใช่ผลิตภัณฑ์สุดท้าย

ขั้นกำหนดอัตราขั้นที่มี Eₐ สูงสุด (ยอดสูงสุดในกราฟ) — เปรียบเหมือนคอขวด ทำให้ปฏิกิริยาโดยรวมเร็วได้ไม่เกินขั้นนี้ ต่อให้ขั้นอื่นเร็วแค่ไหนก็ตาม
สารมัธยันตร์เสถียร​พอที่จะ​แยกตัว​ออกมา​ได้​ชั่วขณะ (ต่างจาก​สารเชิงซ้อน​กัมมันต์​ที่อยู่​บนยอด แยกไม่ได้เลย) แล้ว​ถูกใช้ต่อ​ในขั้นถัดไป​จนหมด จึง​ไม่ปรากฏ​ในสมการรวม
2.5

ตัวเร่งปฏิกิริยา — ลด Eₐ แต่ไม่แตะ ΔE

ตัวเร่งปฏิกิริยาสร้างเส้นทางใหม่ที่มี Eₐ ต่ำกว่าเดิม ให้อนุภาคข้ามไปได้ง่ายขึ้น แต่ระดับพลังงานของสารตั้งต้นและผลิตภัณฑ์ไม่เปลี่ยนเลย — ลองกดปุ่มด้านล่างเทียบดู

สังเกตปลายทั้งสองข้าง (สารตั้งต้น/ผลิตภัณฑ์) — ไม่ขยับเลยไม่ว่าจะกดปุ่มไหน มีแต่ยอดที่เปลี่ยน เส้นประจางคือระดับเดิมตอนไม่มีตัวเร่ง ไว้เทียบ

✗ เข้าใจผิด✓ ที่ถูกต้อง

ตัวเร่งปฏิกิริยาทำให้ได้ผลิตภัณฑ์มากขึ้น

ได้ปริมาณผลิตภัณฑ์เท่าเดิม แค่ไปถึงเร็วขึ้น — ระดับพลังงานผลิตภัณฑ์ (และ ΔE) ไม่เปลี่ยน

✗ เข้าใจผิด✓ ที่ถูกต้อง

ตัวเร่งปฏิกิริยาลดพลังงานของสารตั้งต้น

ตัวเร่งลดเฉพาะ Eₐ (ความสูงของยอด) พลังงานสารตั้งต้นและผลิตภัณฑ์อยู่ที่เดิมเป๊ะ

  1. การเกิดปฏิกิริยาเคมีระหว่างสารตั้งต้นที่เป็นของแข็งกับของเหลวไม่สามารถอธิบายได้โดยใช้ทฤษฎีการชน
  2. ปฏิกิริยาเคมีเกิดขึ้นได้ ถ้าอนุภาคของสารตั้งต้นชนกันด้วยทิศทางที่เหมาะสม และมีพลังงานอย่างน้อยเท่ากับพลังงานก่อกัมมันต์
  3. อนุภาคของสารที่ชนกันแล้วเกิดปฏิกิริยาเคมี แต่ละอนุภาคไม่จำเป็นต้องมีพลังงานเท่ากับพลังงานก่อกัมมันต์

1.2 ✓ ถูก

1.3 ✓ ถูก — พลังงานก่อกัมมันต์เป็นพลังงานรวมของคู่อนุภาคที่ชนกัน แต่ละอนุภาคเดี่ยวๆ ไม่จำเป็นต้องมีพลังงานถึงเกณฑ์นั้นเพียงลำพัง
