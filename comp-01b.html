เรื่องอัตราการเกิดปฏิกิริยา
แผ่นที่01 / 07
ปฏิกิริยาที่ศึกษา2H₂O₂ → 2H₂O + O₂
แนบกราฟ · ปริมาตรแก๊สที่เก็บได้เทียบกับเวลา
อัตราเฉลี่ยในช่วง Δt 0.77 cm³ · s⁻¹
อัตรา ณ ขณะหนึ่ง 0.74 cm³ · s⁻¹  ที่ t = 28 s
Δt → 0 · เส้นสัมผัส
ปากกาน้ำเงิน = เส้นตัด → อัตราเฉลี่ย ปากกาแดง = เส้นสัมผัส → อัตราขณะหนึ่ง

ถ้าจะบอกว่าเร็ว ต้องบอกให้ได้ว่า
อะไรเปลี่ยนไปเท่าไร ในเวลาเท่าไร

ความชันของเส้นที่ลากบนกราฟคืออัตรา — เลื่อนเครื่องหมาย t₁ t₂ เข้าหากันจนชิด แล้วดูว่าเส้นตัดที่ลากด้วยปากกาน้ำเงินค่อย ๆ กลายเป็นเส้นสัมผัสที่ลากด้วยปากกาแดงได้อย่างไร

นิยามและหน่วย

อัตรา = − Δ[สารตั้งต้น] / Δt  =  + Δ[ผลิตภัณฑ์] / Δt
Δ คืออะไรค่าตอนหลัง ลบ ค่าตอนแรก เสมอ ไม่ใช่ผลต่างแบบไม่สนลำดับ
ทำไมต้องมีลบสารตั้งต้นลดลง Δ จึงติดลบ ใส่ลบไปหนึ่งตัวเพื่อให้อัตราเป็นบวกเสมอ
อ่านว่าอย่างไร“ความเข้มข้นเปลี่ยนไปกี่โมลต่อลูกบาศก์เดซิเมตร ในหนึ่งวินาที”
หน่วยใช้เมื่อวัดอะไรตัวอย่างปฏิกิริยา
